Install Grimoire Pick Chrome Extension

Get a polished sidebar catalog directly inside the official botc.app game window.

1
Download the Extension

Click the button below to visit the releases page. Download the source code ZIP file and extract it to a folder on your computer.

Get Extension Source
2
Open Extension Settings

Open a new tab in your Chrome browser and navigate to: chrome://extensions/

3
Enable Developer Mode

In the top-right corner of the Extensions page, toggle the Developer mode switch to ON.

4
Load Unpacked Folder

Click the Load unpacked button in the top-left, and select the extracted extension folder.

On your computer, this folder is located at:
C:\Users\jamie\Desktop\GrimoirePick\extension
